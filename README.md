# Anil DJ & Events

A modern, responsive business website for Anil DJ & Events, a professional DJ, sound, lighting, and event management service provider based in Hapur, serving Noida, Ghaziabad, and Delhi NCR.

## Features

- Modern and responsive UI
- Service showcase pages
- Event gallery with lightbox
- WhatsApp contact integration
- SEO optimized metadata and structured data
- Open Graph & Twitter sharing support
- Performance-focused Next.js architecture
- Mobile-friendly design

## Tech Stack

- Next.js 16
- React 19
- Tailwind CSS 4
- Framer Motion
- EmailJS
- Lucide React

## Services Covered

- DJ on Wheels
- Wedding DJ Services
- Sound Systems
- Stage Setup
- Professional Lighting
- Corporate Events
- College & School Events
- Custom Event Management
